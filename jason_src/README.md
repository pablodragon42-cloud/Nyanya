# «За нами пришёл Джейсон, а мой друг — идиот» — исходники ролика

Вертикальный ролик 9:16 (1080×1920, 30 fps, ~66 с) в 2D-стиле предыдущего ролика
(`video_src/`): плоские фигуры, тёмные контуры, одна сторона в тени, зерно и виньетка,
субтитры Oswald Bold с жёлтым активным словом. Всё рисуется кодом, без 3D.

| Файл | Что делает |
|---|---|
| `timeline.py` | берёт озвучку (`voice.mp3`) и слова из распознавания (`words_asr.json`), подгоняет тайминги под реальную речь, ставит текст сценария, вставляет 4 комедийные паузы → `timeline.json` + `build/voice.wav` |
| `gfx.py` | камера (наезды, поворот, тряска), холст с суперсэмплингом, зерно/виньетка |
| `chars.py` | персонажи-марионетки: испуганный друг, тупой друг, Джейсон; позы, мимика, липсинк |
| `sets.py` | локации: сумерки у домика, ночной лес, интерьер с окном, тропа в перспективе, большое дерево |
| `scenes.py` | 18 сцен по сценарию, привязанных к словам диктора |
| `render.py` | склейка кадра: сцены → переходы → субтитры / финальная надпись → пост-обработка |
| `sound.py` | процедурная музыка и звуковые эффекты, сведение под голос → `build/mix.wav` |
| `build.py` | полный сбор: `python build.py` (видео в 4 потока → звук → финальный mp4) |
| `sheet.py` | лист персонажей для проверки дизайна |

Сборка: `pip install numpy scipy pillow`, нужен `ffmpeg`, затем
`python timeline.py && python build.py`. Готовый файл: `../jason_drug_idiot_9x16.mp4`.
