# «За нами пришёл Джейсон, а мой друг — идиот» — мультяшная версия (v2)

Тот же сценарий, озвучка и тайминг, что в `jason_src/`, но в стиле ролика про хомяка
(`hamster_src` в ветке `claude/lucid-ptolemy-dy7zqz`): яркий мультяшный 2D на Canvas,
толстые контуры, игровой HUD («УРОВЕНЬ УГРОЗЫ», «IQ ДРУГА», «ШАНС ВЫЖИТЬ», «НЕЛОВКОСТЬ»),
стикеры, ономатопея, вставки-реакции, караоке-субтитры с тегами «Я» / «ДРУГ».

| Файл | Что делает |
|---|---|
| `prep.py` | слова, реплики и липсинк из `../jason_src/timeline.json` → `data.js` |
| `core.js` | движок из ролика про хомяка: камера, примитивы, эффекты |
| `chars.js` | испуганный друг, тупой друг, Джейсон |
| `world.js` | локации: закат у домика, ночной лес, домик снаружи и внутри, тропа, дерево |
| `hud.js` | заставка, HUD-шкалы, субтитры, стикеры, пузыри, финальная надпись |
| `scenes.js` | 34 шота по 18 сценам сценария, переходы |
| `render.js` / `snap.js` | рендер кадров через Playwright / стоп-кадры для проверки |
| `build.sh` | полный сбор → `../jason_drug_idiot_v2_9x16.mp4` |

Звук: `../jason_src/sound.py` с `CARTOON=1` (добавляет звуки стикеров и HUD).
Нужны `node` + `playwright`, `ffmpeg`, Python с `numpy scipy`.
